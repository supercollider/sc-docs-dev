    LinkJump : UGen : AbstractFunction : Object

    UGen that jumps to a position within a quantum of the server's Link clock
    Source: LinkUGen.sc
    See also: LinkClock, LinkTempo, LinkPhase

    Description

    LinkJump jumps to a specific position within the quantum of a Link clock, either for the Link clock of the server or for all Link clocks on the network.

    For further information on Link clock see LinkClock and the official Link documentation at https://ableton.github.io/link/ .

    Class Methods

    LinkJump.kr(gate: 0.0, beat: 0.0, quantum: 4.0, force: 0.0)

    If the server clock has not been enabled via LinkPhase.start, it will return -1.0, otherwise it will return 0.0.

    Arguments:

    gate

    A gate signal >0 will invoke a jump using the following arguments.

    beat

    This value b should be within 0 \leq b < q, where q is the provided quantum.

    quantum

    The quantum value for to identify the beat within the induced grid.

    force

    If force is > 0, it will "rudely re-map the beat/time relationship for all peers in a session". Otherwise it will "attempt to map the given beat to the given time in the context of the given quantum", which behaves depending on if there are other clients within the network or not.
