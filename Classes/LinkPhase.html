    LinkPhase : UGen : AbstractFunction : Object

    UGen to access the phase of the server's Link clock
    Source: LinkUGen.sc
    See also: LinkClock, LinkTempo, LinkJump

    Description

    LinkPhase allows to access the phase of a shared Link clock. Such a Link clock can be e.g. LinkClock of sclang, allowing to synchronize an sclang pattern with sequencing on the server.

    NOTE: Each SuperCollider server only uses one Link clock internally. Multiple units of LinkPhase and other Link clock UGens will use the same shared clock.

    For further information on Link clock see LinkClock and the official Link documentation at https://ableton.github.io/link/ .

    Class Methods

    LinkPhase.start(server)

    Join or create a Link session within the network.

    Arguments:

    server

    A Server, defaults to Server: -default.

    LinkPhase.stop(server)

    Exit a Link session within the network. All informations from the Link session will be set to -1.0.

    Arguments:

    server

    A Server, defaults to Server: -default.

    LinkPhase.setTempo(tempo, lag: 0.0, curve: 'exp', server)

    Helper method to set the tempo of the server's Link clock in cps (cycles per second).

    NOTE: See also LinkTempo.

    Arguments:

    tempo

    New tempo of the Link session in cycles per second.

    lag

    If >0.0, the current tempo will be faded into the target tempo over this value in seconds using an Env. If this value is 0.0, the clock will jump immediately to the new tempo.

    NOTE: Having multiple overlapping cross-fade processes can result in undefined behavior since they publish conflicting values.

    curve

    See curve parameter of Env: -new

    server

    A Server, defaults to Server: -default.

    LinkPhase.kr(quantum: 4)

    Returns the phase of the clock, which goes from [0, q) where q is the given quantum. If the server clock has not been enabled via LinkPhase.start, it will return -1.0.

    Arguments:

    quantum

    The quantum is the value that the step count of the clock is taken modulo by. Since the global steps on the Link clock are shared among all clients, clients with the same quantum will share the same phase.
