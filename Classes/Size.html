      Size : Object

      A simple geometry class representing width and height.
      Source: Size.sc
      See also: Point, Rect, Image, QPenPrinter

      Description

      Size represents a two-dimensional extent, consisting of a width and a height. It is used in classes that require explicit dimensions, such as Image and QPenPrinter.

      Class Methods

      Size.new(width: 0, height: 0)

      Create a new Size instance with the given width and height.

      Arguments:

      width

      The width component. Typically an Integer or an Float, but accepts any built-in subclasses of Number.

      height

      The height component. Typically an Integer or an Float, but accepts any built-in subclasses of Number.

      Returns:

      A new Size instance.
