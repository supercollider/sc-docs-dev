    LinkTempo : UGen : AbstractFunction : Object

    UGen that gets and sets the tempo of the server's Link clock in cycles per second
    Source: LinkUGen.sc
    See also: LinkPhase, LinkClock, LinkJump

    Description

    An UGen that gets and sets the tempo of the server's Link clock in cycles per second (cps), such that the tempo can be modulated through a signal. Ableton Link internally uses BPM which gets converted by the server to cps by dividing the BPM value by 60. See LinkPhase for examples.

    Class Methods

    LinkTempo.kr(gate: 0.0, tempo: 1.0)

    Returns the current tempo of the server's Link clock in cps (cycles per second). If the server clock has not been enabled via LinkPhase: *start, it will return -1.0.

    Arguments:

    gate

    If >0, the tempo (second argument) will be used to set the tempo of the server's Link clock and the new tempo will be published to the other clients.

    tempo

    The tempo to be set in cps (cycles per second). Ableton Link uses BPM internally and only allows bpm values between [20, 999], which translates to [\frac{1}{3}, 16.65] cps.

    NOTE: See also LinkPhase: *setTempo
