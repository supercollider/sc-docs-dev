    PostWindowURLHandler

    Used to respond when clicking links in the post window.
    Location: NOT INSTALLED!
    See also: ScIDE, Document

    Description

    Used to respond to specific URLs when clicking links in the post window. For example, when clicking on a file:// link, by default this will open the file.

    Here is an example of how this class can be used.

    When the user clicks on a URL in the post window with the scheme scdoc, open the help file in the IDE help browser.

    Class Methods

    .register

    Arguments:

    name

    A Symbol representing the scheme of the URI. For example, if the URL is bang://hello then the name should be \bang.

    fn

    A Function accepting one argument, which is the full url as a String.

    .new

    Used to trigger any registered action for the scheme if present, otherwise calls a default action, which posts a warning. This is no usually called by the user, but by the IDE backend.

    Arguments:

    scheme

    The scheme of the URI.

    url

    The full url, including the scheme.
